## 線上使用
開啟 `index.html`（或 GitHub Pages 網址）。

## 兩條路，入口分開

| 對象 | 走法 | 頁面 |
|---|---|---|
| 正在上這一冊（七年級） | 照**課本章節**，段考取向 | `chapter.html`、`book.html`、`globe.html` |
| 回頭複習（八年級） | 照**會考能力**，跨章節 | `map` / `contour` / `coord` / `rain` / `landform` |

段考考的是「這一節教了什麼」，會考考的是「跨章節把工具拿出來用」——同一冊課本，兩種讀法。

## 資料來源
- 課本章節、頁碼、學習課題／學習check：翰林版七上社會（地理）第一篇，逐頁核對。
- 會考題與統計：國中教育會考官方「試題分析」（111–114，含選項百分比）與試題本（115，無官方分析）。
- 五年中屬七上地理範圍者共 **38 題**，為逐題核對原卷挑出，非依官方學習內容代碼分類。
- 段考題：新北市立丹鳳高級中學 112–114 學年度七年級上學期社會科段考卷（地理科第 1–17 題），共 153 題。
  章節歸屬一律以**翰林這一冊**為準，不採卷面分段；附圖題不放原圖，只列題目與答案。

## 整理過程中的三個發現

1. **將近一半的命中題用國外情境包裝**（唐詩湖北、玻里尼西亞、南非開普敦、極地投影圖），
   但考的都是本冊教的判讀工具。若照關鍵字掃「臺灣」會全數漏掉。
2. **超過一半的題同時用到兩個章節**。第 1 章的地圖與座標是後面每章的工具，
   所以單元不照章節切、改照能力切。
3. **官方的學習內容代碼標的是「情境屬於哪個單元」，不是「作答需要什麼能力」**。
   例：111-26 用瑞士鐵路情境、官方掛「交通」，實際考的是地形剖面圖判讀。

## 🔴 內容原則
- 說明文字一律**自行撰寫**，只借課本的標題與頁碼，不複製課本內文、不放課本圖片。
- **本冊「影響臺灣氣候的因素」只列緯度、地形、季風三項，沒有洋流。**
  參考書常補上洋流，但這一冊沒教——站上不會多教，以免段考寫了反而扣分。
